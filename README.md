# ML-Scoping-Review-Appendix
Supplementary materials and appendices for a scoping review on Machine Learning applications.

# Supplementary Materials: Machine Learning Scoping Review (N = 41)

## Project Overview
This repository hosts the data appendix tables for my thesis, which presents a scoping review of **41 included studies** utilizing Machine Learning (ML) methodologies. 

These tables provide detailed insights into the study characteristics, clinical populations, model structures, and features analyzed in the review.

## Appendix Tables Index

* **Appendix Table 1: Detailed Summary of Study Features and Research Context**
  * Broad overview of the metadata, study locations, and research environments.
* **Appendix Table 2: Population & Clinical Characteristics**
  * Cohort demographics, clinical settings, and patient data metrics.
* **Appendix Table 3: Machine Learning Models and Methodologies**
  * Breakdown of training protocols, validation techniques, and pipeline structures.
* **Appendix Table 4: Features Included in ML Models**
  * Exhaustive list of variables, predictors, and data inputs fed into the models.
* **Appendix Table 5: ML Algorithms Used and Corresponding Feature Studies**
  * Cross-referencing mapping of specific algorithms against their utilized feature sets.
